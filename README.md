# 📝 Test Management System

A full-stack online test management system for admins and students.

## 🔗 Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js + Express
- **Database:** MySQL

## 👥 Features
- Admin: Create, edit, publish tests
- Student: Take tests, view results
- Timer-based test attempts
- Score calculation

## 🚀 Run Locally

### Backend
```bash
cd backend
npm install
cp .env.example .env  # fill in your DB credentials
node server.js
```

### Frontend
```bash
cd frontend
npm install
npm start
```
